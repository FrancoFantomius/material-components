# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.0   | :white_check_mark: |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `@francofantomius/material-components`, please report it responsibly:

- **Email**: Contact `mail@francofantomius.com` with the vulnerability details and reproduction steps.
- **GitHub**: Open a private advisory report at [Security Advisories](https://github.com/FrancoFantomius/material-components/security/advisories).

Please do not open public issues for security vulnerabilities. We will investigate and release patches promptly.
